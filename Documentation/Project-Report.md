 Project Report

 APT Campaign & Multi-Stage RAT Analysis

 1. Introduction
This project studies Advanced Persistent Threat (APT) campaigns and multi-stage malware attacks using Remcos RAT as a case study.

 2. Aim
To understand multi-stage malware behaviour, Command and Control communication, and MITRE ATT&CK techniques.

3. Objectives
- Study APT campaigns.
- Understand Remcos RAT.
- Analyse PowerShell execution techniques.
- Study C2 beaconing patterns.
- Map observed techniques to MITRE ATT&CK.
- Identify detection and prevention methods.

 4. Tools Used
- Wireshark
- VirusTotal
- MalwareBazaar
- MITRE ATT&CK
- Google Threat Intelligence

5. Conclusion
This project helps develop an understanding of malware behaviour, network analysis, threat detection, and cybersecurity defence techniques.

Note: Practical analysis must use safe, authorised and isolated environments.
